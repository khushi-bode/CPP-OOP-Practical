## Problem Statement
Write a C++ program to demonstrate the use of a class, constructor, destructor, and user-defined functions by implementing a simple Bank Account system with user input.

## Objectives
1. To understand the concept of classes and objects in C++.
2. To implement constructors and destructors.
3. To create and use user-defined functions with user input.

## Concepts Used
- Class
- Object
- Constructor
- Destructor
- User-defined functions
- Encapsulation
- Input and Output

## User-defined Functions
- `deposit()` adds money to the account balance.
- `withdraw()` withdraws money when sufficient balance is available.
- `display()` displays account details.
